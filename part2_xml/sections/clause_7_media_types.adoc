== Media Types for any data encoding(s)

GeoSciML 5.0 data conforming to the logical model defined in Part 1 of GeoSciML can be encoded in GML-conformant XML documents.  The standard MIME-type and sub-type for GML data should be used to indicate the encoding in internet exchange, as specified in _MIME Media Types for GML,_ namely

`application/gml+xml`
